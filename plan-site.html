Cascais Local Guide

My website plan

1. Site Name

Cascais Local Guide

This name is simple and tells visitors that the site is about places and useful information in Cascais.

Possible domain: cascais-local-guide.com

2. Site Purpose

The website will help residents and visitors discover beaches, restaurants, walking areas, and local events in Cascais. It will include a list of places, details about each place, and a simple form for visitors to save or send a place suggestion.

3. Scenarios

  • Which beach is good for a quiet swim in Cascais?
  • Where can I find a local restaurant near the old town?
  • What is happening in Cascais this weekend?

Ocean Teal: headers, buttons, and important headings.

Sand: page background and colored sections.

Dark Gray: body text and borders.

White: main content boxes and the wireframe background.

5. Typography

Georgia will be used for the website heading and section titles because it is easy to read and has a local, classic style.

Arial will be used for paragraphs, links, buttons, and form text because it is clear on small screens.
